# SCROLL_NARRATIVE_CONTINUITY_SPEC.md
Date: 2026-04-03

## Purpose
Fix fast-disappearing content and create cinematic scroll flow with:
- hold zones
- smooth handoffs
- readable transitions

---

## Core Principles

1. Hold Time
Each section must stay readable before transitioning.

Structure:
- Entry (20%)
- HOLD (40–50%)
- Handoff (20–30%)

---

2. Handoff (Loop Effect)
Sections must overlap:
- current fades to ~70%
- next rises to 100%

Never hard cut.

---

3. Scroll ≠ Direct Animation
Scroll controls STATE, not every pixel animation.

---

4. Pin Strategy
Use short pinning for clarity.

---

5. Text Behavior
Text must:
- enter
- stay readable
- exit slowly

---

6. Continuity Rules
- same object position
- same lighting
- same camera

---

## Timing Model

Good:
0–20 enter
20–60 HOLD
60–80 handoff
80–100 next

---

## Success Criteria
- readable text
- smooth transitions
- premium pacing
