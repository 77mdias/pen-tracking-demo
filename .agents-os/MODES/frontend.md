# Mode: Frontend

## Goal

Deliver user-facing interfaces with strong UX, maintainable structure, and efficient rendering.

## Priorities

- UI clarity
- page composition
- server/client boundary discipline
- accessibility
- state simplicity
- loading/empty/error states

## Preferred Order

1. route/page structure
2. data contract alignment
3. UI shells
4. components
5. interactions
6. validation states
7. polish

## Rules

- prefer server components where possible
- keep client components minimal
- avoid unnecessary global state
- design for real data and edge states
