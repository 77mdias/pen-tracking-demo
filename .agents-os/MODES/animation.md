# Mode: Animation

## Goal

Deliver high-quality motion and immersive visual experiences without harming usability or performance.

## Priorities

- smoothness
- rendering performance
- interaction feel
- responsiveness
- scroll control
- bundle discipline

## Preferred Order

1. define motion goal
2. choose technique
3. isolate animation layer
4. test performance
5. refine timing
6. ensure fallback behavior

## Rules

- prefer 60fps-friendly solutions
- avoid heavy unnecessary abstractions
- separate visual logic from business logic
- use progressive enhancement
- test trackpad, wheel, touch, and keyboard behavior when relevant
