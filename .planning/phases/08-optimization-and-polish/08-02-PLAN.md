   Delete these two lines:

   These are never read. The accent light color is set directly via `accentLightRef.current.color.set(acc.color)` on line 126.

   Change:
   ```tsx

   ```
   To:
   ```tsx

   ```
   `Color` is only used by the dead useMemo calls. No other reference exists in the file.

3. **Keep `useMemo` in the react import** (line 10):
   `useMemo` is still used on line 37 for the `penModel` clone. Do NOT remove it from the import.

4. **Optimize `cam.updateProjectionMatrix()`** (currently line 145):
   Currently called every frame unconditionally. Only needed when FOV changes.

   Replace:
   ```tsx
   cam.fov = lerp(cam.fov, targetFov, camFactor);
   cam.updateProjectionMatrix();
   ```

   With:
   ```tsx
   const newFov = lerp(cam.fov, targetFov, camFactor);
   if (Math.abs(newFov - cam.fov) > 0.001) {
     cam.fov = newFov;
     cam.updateProjectionMatrix();
   }
   ```

   This skips the matrix recalculation when FOV hasn't meaningfully changed (saves a matrix multiply per frame in the common case where no section pose is active and FOV is stable).
