# Plan 07-01: HeroFallback — Premium Non-WebGL Visual

## Objective

Upgrade the `HeroFallback` component from a stub-quality abstract glass circle to a premium video-driven pen visual that maintains the cinematic feel when WebGL is unavailable. The text/CTA layer (HeroContent/HeroMobile) renders independently above the fallback — this plan only improves the **background visual layer**.

## Context

**Architecture (do NOT change):**
- `HeroSection.tsx` line 94–95 routes `shouldUseFallback ? <HeroFallback className="absolute inset-0 z-[1]" /> : <HeroCanvas />`
- The `className` prop is applied to HeroFallback's root div and provides `absolute inset-0 z-[1]` positioning — never remove this
- Text/CTA renders in a separate `<section>` element above the scene layer (z-10 vs z-1)

**Current problems in `HeroFallback.tsx`:**
1. Video has `opacity-40 mix-blend-screen` → nearly invisible
2. Glass circle placeholder is abstract, not a pen representation

**Assets available:**
- `/public/videos/animation.mp4` (1.2MB) — pen animation video, already wired in

**Design tokens:** background `#050a14`, primary blue `#007bff`

## Tasks

### Task 1: Upgrade HeroFallback Video Visibility and Remove Glass Circle Stub

**Objective:** Make the pen animation video clearly visible as the fallback visual, replacing the abstract glass circle with a subtle pen spotlight glow that matches the R3F lighting aesthetic.

**Files:**
- `src/components/hero/HeroFallback.tsx` — rewrite the component body

**Implementation:**

Replace the full component body of `HeroFallback.tsx` with:

1. **Keep** the radial gradient background layer (line 11) — it provides the ambient blue glow at top
2. **Fix the video element:**
   - Remove `mix-blend-screen` class
   - Change `opacity-40` to `opacity-70`
   - Set `preload="auto"` when motion enabled (ensures first frame loads), `preload="metadata"` when reduced (lighter)
   - Keep existing: `autoPlay={!reducedMotion}`, `loop={!reducedMotion}`, `muted`, `playsInline`
   - When `reducedMotion=true`, video doesn't autoplay — the first frame is shown statically
3. **Keep** the gradient-to-transparent overlay (line 23) for bottom fade
4. **Replace the glass circle** (lines 25–29) with a pen spotlight glow:
   ```tsx
   <div className="absolute inset-0 flex items-center justify-center">
     <div className="h-72 w-72 rounded-full bg-gradient-to-b from-[#007bff]/20 via-transparent to-transparent blur-2xl md:h-96 md:w-96" />
   </div>
   ```
   This mimics the R3F scene's blue rim light as a soft glow behind the video pen, creating visual continuity.

The complete updated component should be:

```tsx
'use client';

type HeroFallbackProps = {
  className?: string;
  reducedMotion?: boolean;
};

export default function HeroFallback({ className, reducedMotion = false }: HeroFallbackProps) {
  return (
    <div className={className}>
      {/* Ambient blue glow — matches R3F scene lighting */}
      <div className="absolute inset-0 bg-[radial-gradient(circle_at_50%_20%,rgba(0,123,255,0.2),transparent_60%)]" />

      {/* Pen spotlight glow — replaces abstract glass circle */}
      <div className="absolute inset-0 flex items-center justify-center">
        <div className="h-72 w-72 rounded-full bg-gradient-to-b from-[#007bff]/20 via-transparent to-transparent blur-2xl md:h-96 md:w-96" />
      </div>

      {/* Pen animation video — now prominently visible */}
      <video
        className="absolute inset-0 h-full w-full object-cover opacity-70"
        src="/videos/animation.mp4"
        autoPlay={!reducedMotion}
        loop={!reducedMotion}
        muted
        playsInline
        preload={reducedMotion ? "metadata" : "auto"}
      />

      {/* Bottom fade to page background */}
      <div className="absolute inset-0 bg-gradient-to-t from-[#050a14] via-[#050a14]/55 to-transparent" />
    </div>
  );
}
```

**Key changes from current:**
- `opacity-40 mix-blend-screen` → `opacity-70` (no blend mode)
- Glass circle div removed entirely
- Pen spotlight glow added (soft blue, matches R3F lighting)
- `preload` is `"auto"` when motion enabled (ensures first frame loads), `"metadata"` when reduced (lighter)
- Video element moved after the glow so it renders on top of the glow layer

### Task 2: Add `aria-hidden` to HeroCanvas Wrapper

**Objective:** The HeroCanvas wrapper `<div>` is missing `aria-hidden="true"`. The 3D canvas is decorative and inaccessible to screen readers. Fix this so the fallback path (HeroFallback, which already has no interactive elements) and the canvas path are both properly hidden from assistive technology.

**Files:**
- `src/components/hero/HeroCanvas.tsx` — add `aria-hidden="true"` to the outer wrapper div

**Implementation:**

In `HeroCanvas.tsx`, line 31, change:
```tsx
<div className="absolute inset-0">
```
to:
```tsx
<div className="absolute inset-0" aria-hidden="true">
```

This marks the entire 3D canvas as decorative. Screen readers will skip it entirely, which is correct — the pen is a visual decoration, not interactive content.

```bash

```
