# Plan 07-02: Reduced Motion Audit — Full Compliance

## Objective

Close the two remaining gaps in `prefers-reduced-motion` compliance: (1) CSS transitions on interactive elements still animate when reduced motion is enabled, and (2) `HeroMobile` has no entrance animation (so there's nothing to gate). This plan adds the CSS transition kill-switch and implements the HeroMobile entrance animation with a proper `reducedMotion` gate — when reduced motion is active, all content is immediately visible with zero animation.

## Context

**What's already done (do NOT rewrite):**
- GSAP timeline: `useHeroTimeline.ts` — `gsap.set()` with immediate values when `reducedMotion=true` ✅
- R3F: `HeroCanvas.tsx` — `frameloop="demand"` freezes 3D ✅
- Scroll: `useHeroScrollProgress.ts` — early-returns 0 ✅
- Video: `VideoBackground.tsx` / `HeroFallback.tsx` — `autoPlay` gated ✅
- CSS animations: `globals.css` line 271 block — decorative animations stopped ✅
- Ambient/scroll-cue: hidden via conditions in `HeroSection.tsx` ✅

**Gaps to close:**
1. **CSS transitions:** `globals.css` reduce block does NOT disable `transition` properties. Button hover effects (`transition-all duration-150` on primary CTA, `transition-all duration-200` on secondary CTA) still animate.
2. **HeroMobile entrance:** Currently `void reducedMotion` — no animation exists. Phase 6 deferred this to Phase 7. We add a GSAP entrance (stagger CTA → headline → subheadline) with a `reducedMotion` gate that sets content immediately visible.

**Architecture constraints:**
- ONE animation system per element — GSAP owns all DOM choreography
- Use `useGSAP` from `@gsap/react` (never raw `useEffect` for GSAP)
- Use `gsap.matchMedia()` or the `reducedMotion` prop guard pattern (match `useHeroTimeline.ts`)
- HeroMobile uses CSS classes `.hero-headline`, `.hero-subheadline`, `.hero-cta` for GSAP targeting (already present from Phase 6)

**Existing pattern to follow (from `useHeroTimeline.ts`):**
```typescript
useGSAP(() => {
  if (reducedMotion) {
    gsap.set([".hero-headline", ".hero-subheadline", ".hero-cta"], {
      opacity: 1, y: 0,
    });
    return; // no timeline created
  }
  const tl = gsap.timeline({ defaults: { ease: "power2.out" } });
  // ...
}, { scope, dependencies: [reducedMotion], revertOnUpdate: true });
```

## Tasks

### Task 1: Add CSS Transition Kill-Switch to Reduced Motion Block

**Objective:** Disable all CSS transitions when `prefers-reduced-motion: reduce` is active, ensuring button hover effects and any other transitional decorations are instant.

**Files:**
- `src/app/globals.css` — extend the existing `@media (prefers-reduced-motion: reduce)` block

**Implementation:**

Find the existing `@media (prefers-reduced-motion: reduce)` block (starting at line 271). Inside it, **after** the existing `animation: none !important` rules, add the universal transition kill-switch:

```css
  /* Kill all CSS transitions — button hover states, decorative fades, etc. */
  *,
  *::before,
  *::after {
    animation-duration: 0.01ms !important;
    transition-duration: 0.01ms !important;
  }
```

This replaces the existing per-selector `animation: none` rules with a universal approach that covers both animations AND transitions. The per-selector `animation: none` rules above it can remain for backward compatibility, but the universal block is the catch-all.

**Why `0.01ms` instead of `0` or `none`:** Using `0.01ms` ensures `animationend`/`transitionend` events still fire (some JS relies on them). Using `none` or `0` may break GSAP callbacks that listen for CSS animation events.

**Safety:** All transitions in this project are purely decorative (button hover aesthetics). Focus rings use `focus-visible:ring-*` which is an instant style change, not a transition — unaffected by this rule.

### Task 2: Implement HeroMobile Entrance Animation with Reduced Motion Gate

**Objective:** Add a staggered entrance animation to HeroMobile (CTA → headline → subheadline) using GSAP, gated by `reducedMotion`. When reduced motion is active, all content is immediately visible at full opacity — no animation plays.

**Files:**
- `src/components/hero/HeroMobile.tsx` — add `useRef`, `useGSAP`, entrance timeline, reduced motion gate

**Implementation:**

Update `HeroMobile.tsx`:

1. **Add imports:** `useRef` from `react`, `gsap` from `gsap`, `useGSAP` from `@gsap/react`
2. **Add container ref:** `const containerRef = useRef<HTMLDivElement>(null);` — assigned to the root `<div>`
3. **Remove** `void reducedMotion;` line — the prop is now actively used
4. **Add `useGSAP` hook** following the verified pattern:

```tsx
useGSAP(() => {
  if (reducedMotion) {
    gsap.set([".hero-cta", ".hero-headline", ".hero-subheadline"], {
      opacity: 1,
      y: 0,
    });
    return;
  }

  // Set initial state (hidden) — GSAP will animate FROM these values
  gsap.set([".hero-cta", ".hero-headline", ".hero-subheadline"], {
    opacity: 0,
    y: 16,
  });

  const tl = gsap.timeline({
    defaults: { ease: "power2.out" },
    delay: 0.2,
  });

  tl.to(".hero-cta", { opacity: 1, y: 0, duration: 0.6 })
    .to(".hero-headline", { opacity: 1, y: 0, duration: 0.7 }, "-=0.3")
    .to(".hero-subheadline", { opacity: 1, y: 0, duration: 0.5 }, "-=0.25");
}, { scope: containerRef, dependencies: [reducedMotion], revertOnUpdate: true });
```

5. **Attach ref** to the root div: change `<div className="mx-auto ...">` to `<div ref={containerRef} className="mx-auto ...">`

**Complete updated file:**

```tsx
'use client';

import { useRef } from "react";
import gsap from "gsap";
import { useGSAP } from "@gsap/react";
import HeroCTA from "@/components/hero/HeroCTA";

type HeroMobileProps = {
  reducedMotion?: boolean;
};

export default function HeroMobile({ reducedMotion = false }: HeroMobileProps) {
  const containerRef = useRef<HTMLDivElement>(null);

  useGSAP(() => {
    if (reducedMotion) {
      gsap.set([".hero-cta", ".hero-headline", ".hero-subheadline"], {
        opacity: 1,
        y: 0,
      });
      return;
    }

    gsap.set([".hero-cta", ".hero-headline", ".hero-subheadline"], {
      opacity: 0,
      y: 16,
    });

    const tl = gsap.timeline({
      defaults: { ease: "power2.out" },
      delay: 0.2,
    });

    tl.to(".hero-cta", { opacity: 1, y: 0, duration: 0.6 })
      .to(".hero-headline", { opacity: 1, y: 0, duration: 0.7 }, "-=0.3")
      .to(".hero-subheadline", { opacity: 1, y: 0, duration: 0.5 }, "-=0.25");
  }, { scope: containerRef, dependencies: [reducedMotion], revertOnUpdate: true });

  return (
    <div ref={containerRef} className="mx-auto flex w-full max-w-sm flex-col items-center text-center px-6">
      {/* 1. Editorial badge — identical classes to HeroContent badge */}
      <div className="border-gradient-spin inline-flex items-center gap-2 bg-black/60 px-4 py-1.5">
        <span className="h-1.5 w-1.5 rounded-full bg-[#ef233c] shadow-[0_0_8px_#ef233c]" />
        <span className="font-inter text-[10px] uppercase tracking-[0.2em] text-zinc-400">
          Smart Pen Premium Demo
        </span>
      </div>

      {/* 2. CTA — primary, full-width on mobile. Secondary button suppressed by isMobile=true */}
      <div className="mt-8 w-full">
        <HeroCTA isMobile={true} />
      </div>

      {/* 3. Headline — below CTA, two lines with gradient on second */}
      <h1 className="hero-headline font-display mt-8 text-4xl font-semibold leading-[0.9] tracking-tight text-white drop-shadow-2xl">
        <span className="block">The pen,</span>
        <span className="block text-transparent bg-clip-text bg-gradient-to-r from-white via-white/90 to-white/40">
          reimagined.
        </span>
      </h1>

      {/* 4. Subheadline — short mobile copy */}
      <p className="hero-subheadline font-inter mt-4 text-base font-normal leading-relaxed text-zinc-300">
        Premium writing precision with an intelligent layer built for focus.
      </p>
    </div>
  );
}
```

**Key behaviors:**
- `reducedMotion=true`: GSAP immediately sets opacity:1, y:0 on all elements → content visible instantly, no animation
- `reducedMotion=false`: Staggered entrance — CTA fades in first (CTA-first hierarchy), then headline, then subheadline
- `revertOnUpdate: true` ensures GSAP reverts and re-applies when `reducedMotion` changes (e.g., user toggles OS setting)
- Scope is `containerRef` — GSAP selectors are scoped to this component only, won't leak to desktop HeroContent
