# Plan 10-02: Home Scroll Fix + About Pen Pose

## Goal

Fix the scroll interception bug in `useSnapScroll.ts` that prevents natural scrolling from the last snap section to `AboutSection`. Add a new `about` pen pose and wire a ScrollTrigger so the 3D pen transitions when AboutSection enters viewport.

## Pre-conditions

- Repository cloned and dependencies installed (`bun install` completed)
- Files exist:
  - `src/hooks/useSnapScroll.ts`
  - `src/hooks/useScrollHijack.ts`
  - `src/lib/three/penPoses.ts`
- Home page (`/`) has:
  - Snap scroll sections in `ProductIntroSection`
  - `AboutSection` below the snap container

## Tasks

### Task 1: Fix useSnapScroll.ts to release on last section

**Files:** `src/hooks/useSnapScroll.ts`

**Steps:**

1. Open `src/hooks/useSnapScroll.ts`

2. Locate the `handleWheel` function (lines 101-107):

   **Before:**
   ```typescript
   const handleWheel = (e: WheelEvent) => {
     e.preventDefault();
     if (isTransitioning) return;
     const { deltaY } = e;
     if (Math.abs(deltaY) < threshold) return;
     navigateTo(currentIndex + (deltaY > 0 ? 1 : -1));
   };
   ```

3. **SURGICAL FIX:** Add a guard as the VERY FIRST check, BEFORE `e.preventDefault()`:

   **After:**
   ```typescript
   const handleWheel = (e: WheelEvent) => {
     // If at last section and scrolling down, release to natural scroll
     if (currentIndex === targets.length - 1 && e.deltaY > 0) return;
     e.preventDefault();
     if (isTransitioning) return;
     const { deltaY } = e;
     if (Math.abs(deltaY) < threshold) return;
     navigateTo(currentIndex + (deltaY > 0 ? 1 : -1));
   };
   ```

4. This is a 2-line addition. Do NOT touch any other part of useSnapScroll.ts.

**Validation:**
- `bun run tsc --noEmit` → 0 errors
- `grep -n "targets.length - 1" src/hooks/useSnapScroll.ts` → returns line with the new guard
